## 2. Screenshot Capture Recommendations

1. **Resolution**: 1920x1080 (1080p) or high-DPI retina captures.
2. **Format**: Crisp PNG or optimized WebP.
3. **Data Quality**: Ensure realistic demo data is present (run `npm run seed` in the `backend` directory first).
4. **Theme Consistency**: Capture all screens in a consistent theme mode with clean browser frames.
